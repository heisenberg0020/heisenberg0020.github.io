首次使用

连接你的写作空间

完成一次连接后，就可以在这里登录、写作和发布。

  1. 注册或登录 Decap Turbo选择 Free 方案，保留你自己的一个账号。
  2. 连接主页仓库安装 GitHub 应用时，只选择个人主页这个仓库。
  3. 复制 Site ID，回到这里这是网站标识，不是密码。填入后即可进入登录页。
打开 Decap Turbo ↗

你的写作空间

把今天记下来。

登录后，打开「写随记」，点击「添加一篇随记」。可以直接输入正文、排版和上传图片。
